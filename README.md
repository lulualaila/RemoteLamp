# **SMART LED CONTROL SYSTEM

Menggunakan ESP32 dan Bluetooth**

Proyek ini merupakan aplikasi Android berbasis **Kotlin + Jetpack Compose** yang digunakan untuk mengontrol **Smart LED** melalui koneksi **Bluetooth ke ESP32**. Aplikasi menyediakan dua layar utama: **Scan Device** dan **Control LED** (mengatur warna dan power).

---

## **Fitur Utama**

### **1. Scan & Connect Bluetooth**

* Menampilkan daftar perangkat Bluetooth di sekitar.
* Memilih dan melakukan koneksi ke ESP32.

### **2. LED Control**

* Menyalakan dan mematikan LED dari aplikasi.
* Komunikasi menggunakan Bluetooth serial ke ESP32.

---

## **Teknologi yang Digunakan**

* **Android Studio**
* **Kotlin**
* **Jetpack Compose**
* **Bluetooth**
* **ESP32 (receiver signal + LED controller)**

---

## 📦 **Cara Menggunakan**

1. Download repository ini atau clone:

   ```
   git clone https://github.com/lulualaila/RemoteLamp
   ```
2. Buka proyek di **Android Studio**.
3. Tunggu hingga Gradle selesai sync & dependencies terinstall.
4. Jalankan aplikasi pada emulator atau perangkat Android dengan Bluetooth aktif.
5. Nyalakan ESP32 dan pastikan mode Bluetooth sudah aktif.
6. Scan → pilih perangkat ESP32 → kontrol LED sesuai kebutuhan.

---

## **Catatan**

* Proyek ini merupakan implementasi sederhana untuk demonstrasi komunikasi Android ↔ ESP32.
* Interface dibuat menggunakan **Jetpack Compose**.
