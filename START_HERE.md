## ✨ FITUR UTAMA

### Aplikasi Ini Bisa:

1. ✅ **Kontrol Lamp 1** - ON/OFF individual (pin 13)
2. ✅ **Kontrol Lamp 2** - ON/OFF individual (pin 14)
3. ✅ **Kontrol Semua** - NYALAKAN/MATIKAN semua lampu
4. ✅ **Auto-Sync** - Status selalu akurat saat app dibuka
5. ✅ **Manual Refresh** - Tombol refresh status
6. ✅ **Smooth UI** - Animasi & visual feedback

### Technology Stack:

- 🎨 **UI:** Jetpack Compose + Material 3
- 🏗️ **Architecture:** MVVM Pattern
- ⚡ **State:** StateFlow (Reactive)
- 🔵 **Communication:** Bluetooth SPP
- 🔌 **Hardware:** ESP32 + 2 LEDs
